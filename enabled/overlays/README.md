# Overlays

Nixpkgs overlays. Can be used to patch packages, add packages, or override defaults.

## Files

- `computercraft.nix` - ComputerCraft related overlays
- `dolphin-emu-git.nix` - Dolphin emulator git build overlay
- `dusklight.nix` - Dusklight overlays
- `firefox-nvidia-offload.nix` - Firefox NVIDIA offload tweaks
- `hanabi.nix` - Hanabi-related overlay
- `home-module-option.nix` - Home module option additions
- `hytale-launcher.nix` - Hytale launcher overlay
- `intel-media-sdk.nix` - Intel media SDK overlay
- `vesktop.nix` - Vesktop patches/overlay
