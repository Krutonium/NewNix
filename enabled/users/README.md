# Users

User account configuration and Home Manager integration. Where applicable, per-user Home Manager configs live in `<username>-hm/`.

## Files

- `gryphon.nix` - Gryphon user configuration
- `kea.nix` - Kea user configuration
- `krutonium-hm/` - Krutonium Home Manager configuration
- `krutonium.nix` - Krutonium user/system integration
- `nevvy.nix` - Nevvy user configuration
- `root.nix` - Root user configuration
- `serviceIds.nix` - Service user IDs
