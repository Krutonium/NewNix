# Applications

Configuration for applications and utilities that aren't services and are intended to be shared across hosts. Includes package lists, gaming helpers, scripts, and common application setup.

## Files

- `default-packages.nix` - Common CLI/system packages (git, tmux, btop, ripgrep, usbutils, etc.)
- `gamemode.nix` - GameMode configuration (gamemode package and module setup)
- `nix-settings.nix` - Nix daemon settings (experimental features, substituters, etc.)
- `scripts.nix` - System scripts and helpers
- `steam.nix` - Steam installation/configuration
- `scripts/` - Helper scripts used by modules
