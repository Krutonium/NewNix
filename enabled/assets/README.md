# Assets

Static assets used by the configuration, such as fonts, wallpapers, icons, and other resources.

## Files

- `assets.nix` - Asset module setup
- `fonts.nix` - Font configuration
- `old_assets/` - Legacy assets
- `profile.png` - User/profile image
- `stylix.nix` - Stylix theming configuration
- `supermenu.png` - Menu image
- `wallpaper.png` - Wallpaper image
