# Services

Long-lived services, mostly used on uWebServer but applicable elsewhere. Each module defines a service with its configuration.

## Files

- `anubis.nix` - Anubis anti-bot/proxy protection
- `attic.nix` - Attic binary cache server
- `avahi.nix` - Avahi mDNS/DNS-SD
- `blog.nix` - Blog service
- `ddns.nix` - Dynamic DNS updates
- `deluge.nix` - Deluge torrent daemon
- `filehosting.nix` - File hosting service
- `forgejo.nix` - Forgejo Git forge
- `g600.nix` - Logitech G600 daemon/config
- `gpu-unlock.nix` - GPU unlocking service/module
- `hostKeys.nix` - Host SSH keys management
- `internetRadio2ComputerCraft.nix` - Internet radio to ComputerCraft integration
- `jellyfin.nix` - Jellyfin media server
- `lact.nix` - LACT GPU monitoring/control
- `matrix.nix` - Matrix homeserver (Conduit/Synapse related)
- `minecraftPortForwards.nix` - Minecraft port forwarding setup
- `minecraftServerData.nix` - Minecraft server data/config
- `minecraftServers.nix` - Minecraft server instances
- `moonshine.nix` - Moonshine streaming server
- `nextcloud.nix` - Nextcloud
- `nginxAuth.nix` - Nginx authentication setup
- `nginx.nix` - Nginx reverse proxy
- `nix-serve.nix` - Local Nix binary cache
- `obs-relay.nix` - OBS relay service
- `ollama.nix` - Ollama LLM service
- `overte.nix` - Overte virtual world server
- `plex.nix` - Plex Media Server
- `postgresql.nix` - PostgreSQL database
- `router.nix` - Router/network configuration
- `rtorrent.nix` - rTorrent
- `satisfactory.nix` - Satisfactory dedicated server
- `searx.nix` - SearXNG metasearch
- `ssh.nix` - SSH server configuration
- `stylix.nix` - Stylix service integration
- `syncthing.nix` - Syncthing file sync
- `trilium.nix` - Trilium Notes
- `v4l2loopback.nix` - v4l2loopback kernel module/config (virtual camera)
- `valheim.nix` - Valheim dedicated server
- `vr.nix` - VR related services/config
- `vscode-server.nix` - VSCode server
- `watchtower.nix` - Watchtower container updater
- `webssh.nix` - WebSSH
- `x11vnc.nix` - x11vnc server
- `zerotier.nix` - ZeroTier networking
